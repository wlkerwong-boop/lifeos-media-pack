# 小红书图卡（making-xhs-cards）

## 概述
为小红书做封面 + 内页 HTML 图卡（900×1200，3:4）。产出 HTML 文件，师兄浏览器打开截图即用，不依赖任何外部服务。

## 前置
读 `~/Projects/media-hub/voice.md`。个人随笔转图卡用素面声部；民宿带货用品牌声部（允许 emoji 和平台流行语）。

## 封面公式（一图一主信息）
- 大数字或大标题占画面 1/3 以上；价格、面积、次数等数字必出
- 顶部左上放系列标签（如「AI 实战复盘」）
- 右下「喜舍」方印章 + 底栏「普光 · 一人 AI 军团」+「左滑看正文」
- 参考实现：`~/Projects/media-hub/cover-AI提效是错觉.html`（米白底 #f5f1e8 / 墨绿 #1f3d2b / 橙 #c25e2e，圆章改方章）

## 内页规则
- 3-6 张，每张只讲一个点，第一张 = 封面观点的展开
- 正文字号 ≥34px，行高 ≥1.5，左右留白 ≥70px
- 不放二维码；引流话术放最后一页底栏

## 红线（图卡同样要过）
孩子正脸与全名、真实地址门牌、价格夸大（写实际价，不写「白菜价」）、修行玄虚词。

## 输出与交棒
- HTML 存 `~/Projects/media-hub/`，命名 `cover-标题.html`；PNG 由师兄截图（retina 2x）
- 需要批量生成或转 PNG 自动化时再议，先跑通人工截图流
- 图卡文案定稿后 → checking-before-publish 连同图文一起查

## 常见错误
- 文字溢出 900×1200 画布（写完用浏览器实测一次）
- 字号小于 34px（手机上看不清）
- 用了英文字体栈导致中文回退难看（font-family 以 PingFang SC 开头）
- 封面塞两个观点
